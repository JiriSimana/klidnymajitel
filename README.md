# Klidný majitel — prototyp webu (v5)

Statický prototyp webu **klidnymajitel.cz** pro schválení klientem.
Garantovaný nájem a správa nemovitostí v Plzeňském kraji · provozuje profiservis24 · spolupráce Mix Reality.

## Stránky
- `index.html` — homepage (hero s kalkulačkou, varianty START/JISTOTA/KLID, srovnání, recenze*, FAQ, poptávka)
- `garance-a-cenik.html` — ceník + vizualizace roku s garancí
- `sprava-nemovitosti-plzen.html` — SEO stránka správy
- `pruvodce.html` — blog rozcestník s plánem vydávání
- `pruvodce-*.html` — 13 článků na trendová klíčová slova

## Stav / poznámky
- Recenze označené štítkem „ukázka" a sloty „foto a jméno doplníme" čekají na reálné podklady.
- Formuláře a kalkulačka jsou prototyp (bez backendu).
- `robots.txt` + meta `noindex` blokují indexaci — odstranit při ostrém spuštění.
- Fotky jsou AI podklady (gpt-image), k výměně za reálné focení.
- Právní/daňová tvrzení v článcích ověřit právníkem před publikací.

*Ostrá verze pojede jako Astro → Vercel dle realizačního plánu; tento repozitář slouží ke schválení designu a obsahu.*
